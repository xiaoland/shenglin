# 声邻 / Shenglin Logo 包

基于现有身份扩展，不重新设计。源仓库固定于 `71baa5f5aa54a486484e4a302d181430afc48033`（2026-10-19 获取）。

## 快速使用
- 独立标记：`png/mark/`。浅底选 `brand-on-transparent` 或 `black-on-transparent`；深底优先 `white-on-transparent`。
- 保留青色底板的应用图标：`png/app-icon/`。`transparent` 表示底板外围透明，底板本身保留。
- 原彩固定为上游青色 `#065E6E`；纯白 `#FFFFFF`，纯黑 `#000000`。
- 9 档 PNG：16、24、32、48、64、128、256、512、1024 px。均正方形、RGBA。按实际使用像素挑选，勿将小尺寸版本放大作大标。
- `svg/`：可编辑路径，无嵌入图片、无字体依赖；声波是真透明镂空，不是用背景色伪装。背景与标记单独命名，方便编辑。30 个光学/色彩/背景主版。
- `platform-originals/`：保留原版 Mac 图标、iPad 满版图标、菜单栏单色 SVG，并附 PNG。iPad 版不预裁圆角，按平台要求使用。
- `contact-sheet.png`：背景/色彩总览及 16–128 px 原始像素尺寸对照。

## 光学尺寸与真实几何差异
这是交付包的适配方案，并非声称上游已经批准所有派生版。

| 档位 | 使用尺寸 | 独立标记 | 应用图标 |
|---|---|---|---|
| micro | 16–24 px | 采用上游 MenuBarIcon 的无声波轮廓；相对原独立画板中心放大 14% | 移除亚像素声波孔，底板占画板 87.5% |
| compact | 32–48 px | 五孔合并成三孔；宽度 20→32，中心孔高 134，侧孔高 74；整体放大 6% | 同样三孔；底板占 87.5% |
| regular | 64 px 及以上 | 保持上游五孔几何和 1254 方形画板 | 保持上游 80.46875% 底板及五孔 |

micro 去声波沿用既有菜单栏简化思想；compact 三孔与放大为本次新做的光学派生。外轮廓全部来自原路径，未改变三节点连接身份。小尺寸加大底板沿用上游 `build-macos-icon.sh` 的 16/32 px 方案，并扩展至本包 24/48 px。

原彩在纯黑背景上的对比弱于纯白版；保留供品牌背景配图使用，细小界面标记推荐纯白。白对白、黑对黑等不可见组合没有输出。

## 重建与验证
在本目录执行 `python3 generate.py`，需要 Python 3、Pillow 与 Inkscape。脚本只读本包 source，不访问或修改上游。PNG 通过 Inkscape SVG 渲染。`manifest.json` 记录每个派生 PNG 的尺寸、光学档位、透明度范围与 SHA256；`validation.json` 记录检测结果。

source 保留上游 SVG、README、构建脚本和 LICENSE，文件名前的双下划线代表上游路径分隔符。上游代码许可证为 MIT；品牌标志不因附带代码许可证而自动获得商标授权。
