# iPad 音量可行性探针

这是有界实验，不是可日常使用的音频路由器。源代码使用 Swift、Apple SDK 与 Objective-C 运行时，不包含第三方 iPad 依赖。当前包含用户后来同意的短时 duck 会话测试，声明 audio 后台模式，但没有播放器、音频 I/O、录音或静音循环。实际后台测试仍发生挂起。

启动方式分三种：默认只扫描库和符号，读取系统媒体音量并显示系统 MPVolumeView；`--test-volume` 执行一次私有分类音量降低与条件恢复；`--listen` 启动仅允许 Wi-Fi 的 UDP 实验监听。后两种已经获得本轮实验授权。

私有测试先检查 iPadOS 27 实测的方法 ABI，取得 Audio/Video 分类原值，再降低 0.0625，等待两秒回读。只有同一分类仍等于测试值才恢复已知原值。公开 outputVolume 和系统滑块值分别记录，不能相互替代。这个条件恢复仅用于短时实验，未完整处理并发用户调整、路由切换、进程被杀等产品级情形；不要将它直接部署为日常控制程序。

Wi-Fi 监听使用进程内随机令牌，只接受带令牌和有效期的 ping、volume、duck、hold、stop 命令，最多保留八个短连接。命令包含发送端四秒有效期，超过有效期即拒绝，避免挂起期间积压的动作在回到前台后才执行。duck为三秒，hold为二十秒；停用计时器不能在挂起时保证准时执行，已有真机反例。后台/锁屏对照首先只发ping，确认通道存活后才执行已授权的小幅音量测试。

本机 `sh check.sh` 验证运行时查询的存在/缺失分支并进行未签名构建。普通开发签名已安装到实际 iPadOS 27；首次启动需要的设备端开发者信任已由用户完成。无需再次信任，也不要更改设备安全策略。

已实测：私有 getter/setter 可调用，系统滑块和分类回读均从 0.3375 降至 0.275 并恢复 0.3375。未经激活的 AVAudioSession.outputVolume 始终为 0.35，说明这一路读数在本实验中不适合作独立成功判据。收到 Wi-Fi volume 命令后也成功完成同样步骤。用户拔掉USB后仍完成前台Wi-Fi控制。普通后台/锁屏以及20秒duck无音频IO的后台命令均超时。无线LLDB附加经过减少符号加载后成功，但解锁后台仍失联；独立工作队列心跳也停止，回前台才恢复。更新App后复用调试会话重连失败，新进程连接成功，未形成可靠自动恢复流程。其他声音域与真实外部App听感以同目录上级《可行性结论》为准。

诊断参数 `--heartbeat` 在独立全局工作队列每秒输出时间戳，用于区别应用执行停顿与仅网络失联；它不提供保活。实验结束已退出调试器并终止测试进程。

产品目标允许 Mac 录音状态同步、蓝牙控制/唤醒和 iPad 音频会话协调，但持续静音输出只能用于限时诊断，不能用于日常后台保活；本探针没有实现或运行静音输出。前台局域网命令成功不代表后台或锁屏时能自动收到命令。蓝牙实验验证了另一条后台唤醒路径，用户已同意把它作为产品候选条件。

新参数 `--ble` 启动 Core Bluetooth 外设探针，发布可写 GATT 特征并声明 `bluetooth-peripheral` 后台模式。Mac 测试客户端在 iPad 挂起且 LAN ping 超时后写入，真机后台回调收到 ping，并完成小幅媒体音量降低与条件恢复；锁屏时也已真机通过。探针的测试令牌保存在 iPad Keychain（首次解锁后可读），命令有四秒有效期，仅接受 ping/volume/stop；GATT 写入 ACK 不代表 App 已执行，正式协议还需要应用层确认。`--ble-stop` 或经过认证的 GATT `stop` 可清除实验启用标记、停止广播并移除服务；锁屏收尾时已用后者关闭，并从自身 App 偏好文件确认标记变为 false。

`MacBLEClient.swift` 是本轮 Mac 测试客户端源码。编译后传入 iPad 控制台日志路径，可选第二个参数指定程序启动后等待多少秒再发 ping；再过五秒发短时音量测试。`--interactive` 则在终端等待 `ping`、`volume`、`quit`。它读取日志中的实验令牌，不打印令牌。Keychain 令牌持久化是最小进程恢复准备；当前样例没有产品级配对、状态对账或应用层执行确认。

蓝牙实验增加了蓝牙可用性条件，不能改写成纯 LAN 成功。Mac 客户端进程重启后在后台和锁屏状态均重连成功；iPad 系统回收及重启、用户强制退出和长期断线恢复未完成真机验证。锁屏安装更新后，新版进程处理了旧令牌的 `stop`，但安装更新不同于系统自动回收。解锁状态下，Mac 无线 `devicectl launch --no-activate` 也完成一次后台音量测试；锁屏时同一路径已超时。
