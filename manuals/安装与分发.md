# 安装与分发

## macOS

预发布草稿已附 `Shenglin-macOS-arm64.dmg`，尚未公开。将其中的声邻拖入“应用程序”后启动。当前包仅由 Apple Development 证书签名，尚无 Developer ID 签名和 Apple 公证，因此 macOS 可能阻止从互联网下载的副本运行。这个 DMG 用于已了解开发版限制的测试者，不是完成公开分发签名的安装包。项目目前仅构建和验证 Apple Silicon Mac，最低系统版本为 macOS 14。

要制作可供普通用户下载后直接打开的版本，需要为 App 及内含的虚拟麦克风驱动使用 Developer ID 签名，提交 Apple 公证并把公证凭据附到发布产物。这需要发布者账户中的 Developer ID 证书及公证凭据；当前构建机只有 Apple Development 证书。准备好这些材料后，应重新打包并验证下载后的 DMG，而不是继续使用本预发布的开发签名包。

## iPadOS

目前不提供公开 IPA。iPadOS 不会因为应用源码公开就允许任意设备安装：可供他人无源码安装的常用途径是 TestFlight，或为已登记设备制作 Ad Hoc IPA。两者都需要 Apple Developer Program 的分发签名；Ad Hoc 还要求事先登记每台设备。现有真机包使用开发配置文件，仅适合已获授权的测试设备；其中的配置文件含设备标识，不应上传到公开 GitHub Release。

此外，iPad 版目前依赖私有 `AVSystemController` 属性和音量接口。将它送交 TestFlight 前，必须先处理这项分发风险并验证 App Review 是否接受；不能承诺审核通过。若仍需安装当前开发版，请在 Apple Silicon Mac 上按[开发与诊断](开发与诊断.md)构建，用自己的开发团队签名并通过 Xcode 安装。源码仓库只是当前安装路径，不是产品预期的最终分发方式。
